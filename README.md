# Тестовое задание для AQA стажёра в компании Учи.ру

Исправленные автотесты виджета «База знаний Учи.ру» на главной странице uchi.ru.

## Подготовка к работе

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Установите браузер для Playwright:
```shell
npx playwright install chromium
```

## Запуск тестов

Запустите тесты с помощью команды:
```shell
npx playwright test
```

## Что было исправлено

### 1. Неверный селектор кнопки «Написать нам» (tests/widget.page.ts)
Кнопка на странице имеет класс `cbutton__*` (например `cbutton__InFVD`), а не `btn__*`.
Старый селектор `[class^=btn]` находил другие элементы и не кликал нужную кнопку.
Исправлено на `button[class^=cbutton__]`.

### 2. Поиск элементов не в том контейнере (tests/widget.page.ts)
Методы `getPopularArticles`, `clickWriteToUs` и `getTitle` искали статьи, кнопку
и заголовок внутри `wrapper()` — это элемент с кнопкой открытия виджета на странице.
Всё содержимое открытого виджета находится в другом контейнере — теле виджета
(`getWidgetBody()`, селектор `[class^=widgetWrapper] > [class^=widget__]`).
Из-за этого список популярных статей был пуст и `articles[0]` обращался к `undefined`.
Все три метода переведены на поиск через `getWidgetBody()`.

## Дополнительный тест (сверх задания)

`back button returns to start screen` — проверяет, что кнопка «Назад»
(`data-test=button_back`) на экране статьи возвращает пользователя
к стартовому экрану виджета с заголовком «База знаний Учи.ру».
